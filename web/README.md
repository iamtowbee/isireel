# Web Log Viewer (PWA)

Progressive Web App for viewing iOS logs directly in Safari on iPhone.

## Features

- 🌐 Runs in Safari (no app installation)
- 📱 Add to home screen like a native app
- 🎨 Terminal-style UI with color-coded log levels
- ⚡ Real-time log streaming via WebSocket
- 💾 Works offline after first load
- 🔍 Filtering and search
